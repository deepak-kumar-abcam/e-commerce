Customer-specific pricing agreements are created in the ERP and reach Intershop as files on the
SFTP server, which Boomi loads.

- **Phenomenex** stages them in WebDB first, which pushes them to the SFTP server on a scheduled
  job.
- **SCIEX** publishes them straight from Oracle, on a scheduled job that writes the files to the
  SFTP server over SSH.

The route for Leica Microsystems is not yet documented.
