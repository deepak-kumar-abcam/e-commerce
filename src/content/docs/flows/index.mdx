How data reaches the central instance from the systems that own it. Each flow names the system the
data is mastered in, every hop it takes, and which operating companies it has been documented for.
The [architecture diagrams](/architecture/) show the same systems as one map.

<FlowIndex />

## Reading the diagrams

- **Solid arrows** are live today; **dashed** ones are planned changes.
- **"via Boomi"** marks a hop carried by a Boomi process.
- **Unconfirmed** marks a hop recorded as described but not yet checked.
- Faded, dashed circles are operating companies the flow is not yet documented for.
- Anything not yet confirmed — a system, a schedule, a format — is marked **Not documented** rather
  than guessed.
