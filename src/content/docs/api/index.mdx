## APIs

APIs tagged **Danaher** are built entirely by the platform team. The others are standard Intershop
APIs, some with Danaher endpoints added — counted under **Custom**.

## Danaher custom endpoints

Operations implemented by Danaher code rather than by Intershop, detected from each spec: the
operation's resource class (`x-origin-class`) is in a `com.danaher` package or named `Danaher…`,
or its tag names Danaher or "Custom". The list updates itself with the files, but an endpoint with
none of those markers won't appear.

## Updating the reference

The reference is generated from the YAML files in `openapi/intershop/`, one per API. To refresh
them all from the live Swagger endpoint:

```bash
npm run api:fetch
```

Or replace, add, or delete a YAML file by hand. Either way the sidebar, pages, and the tables above
regenerate — no config changes needed. Restart the dev server after adding or removing a file.
